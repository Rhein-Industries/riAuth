# Security policy

## Supported version

Security fixes are considered for the latest v0.1.x release.

## Report a vulnerability

When private vulnerability reporting is enabled, use **Security → Advisories → Report a vulnerability** in the [riAuth repository](https://github.com/Rhein-Industries/riAuth/security/advisories). Include the affected version or commit, the impact, and steps to reproduce. Please keep exploit details, credentials, and personal data out of public issues.

If the private reporting button is unavailable, open a public issue asking maintainers for a private contact method **without sharing vulnerability details**.

We will acknowledge reports and coordinate a fix and disclosure with the reporter. No response or remediation deadline is promised for this initial release.
